# Дисциплина — релизы

Автообновления и установщики приложения «Дисциплина».

В этом репозитории хранятся только собранные файлы — установщик, blockmap и
служебный `latest.yml`. Исходного кода здесь нет, он находится в приватном
репозитории.

## Скачать установщик

Откройте раздел **Releases** → последний релиз → файл
`Дисциплина-Setup-1.0.0.exe`.

Программа бесплатна. Если приложение полезно — поддержите проект, подробности
внутри самого приложения (раздел «О программе»).
